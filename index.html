怎么玩

默认是自动巡航，鹈鹕会自己找鱼、对准跳台。按 ← → 就切到手动，按 M 切回来。

← → / A D换道
↑ / W冲刺（最高约 49 km/h）
↓ / S刹车
空格原地跳。冲上木头跳台会飞得更高，空中能吃到高处的金鱼
B / 双击画面打铃，鹈鹕会挥翅膀
C镜头：跟随 → 电影 → 自由环绕 → 鹈鹕视角
R天气：晴 → 多云 → 雷雨。雨停后傍晚或上午可能出彩虹
N白天和夜晚之间跳转
P / H截图 / 隐藏界面
Esc暂停

跟随镜头下可以拖动画面转视角。连续吃鱼会叠加倍数（最高 ×8），腾空超过半秒有额外加分，每骑完一圈 +100。最高分保存在本机浏览器。所有模型、贴图、音乐和音效都由代码实时生成，页面没有加载任何图片或音频文件。
